## Highlights

- Added repository-backed release notes via `docs/releases/<version>.md`.
- Updated `./scripts/tag-release.sh` to require release notes before tagging, with an explicit emergency opt-out.
- Updated the GitHub Release workflow to publish release bodies from the matching notes file instead of generated notes.
- Added regression tests for the release notes guard and workflow contract.
- Expanded README and OpenClaw integration docs for delivery directories, retained delivery files, and original-file Telegram delivery.

## Notes

This release is mostly release-process and documentation polish on top of `v0.1.8`. The core OpenClaw/TG image delivery functionality remains the `v0.1.8` feature set.

## Validation

- `./scripts/tag-release.sh` runs local clean CI before pushing the tag.
- The GitHub Release workflow runs secret scan, Go tests, multi-platform builds, and checksum generation.
